Fonte de Audio

Selecione de onde capturar o audio. Use "Audio do sistema" para capturar tudo, ou selecione um dispositivo virtual (ex: VB-Cable) para capturar so o audio do jogo.

Como transmitir so o audio do jogo?

Jeito rapido (sem instalar nada)

  1. Clique direito no icone de som (barra de tarefas) > Mixer de volume
  2. Mute tudo que voce nao quer transmitir (Discord, navegador, musica)
  3. Deixe so o League of Legends (ou o jogo) com volume
  4. Use a opcao "Audio do sistema" acima

Como so o jogo esta fazendo som, so ele sera transmitido. Simples e funciona sem instalar nada.

Jeito avancado (audio 100% isolado)

Se voce quer continuar ouvindo Discord/musica nos fones enquanto transmite so o jogo:

  1. Baixe e instale o VB-CABLE Virtual Audio (gratuito, instala em 10 seg)
  2. Abra Configuracoes > Sistema > Som > Mixer de volume
  3. Em "Apps", mude a saida do jogo para "CABLE Input (VB-Audio)"
  4. Volte aqui, selecione "Dispositivo virtual" e escolha "CABLE Output"

Assim o jogo vai por um canal separado. Voce ouve tudo, quem assiste ouve so o jogo.
